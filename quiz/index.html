    DBMS Quiz

    Students

    • Scan the QR code on the big screen, or open the link and type the room code.
    • Pick any nickname: no sign-up. If the page reloads you rejoin with your score.
    • Tap an answer, or type a query and press Submit. Faster correct answers earn more: up to 1000 points, falling to 500 when the timer reaches zero. The question stays open until the host ends it, and a right answer after the time is up still gets 500.

    Query questions

    • Answers are compared after ignoring letter case (also inside quotes), spacing, a plural s on names (products = product), AS, ASC, INNER, OUTER and the final ;.
    • A wrong query is flagged on the phone right away: edit it and submit again until the time runs out. The points count from when the right query arrives.
    • On the reveal the host sees every different answer and can click one to accept or reject it; scores update at once.

    Fair play

    • Pasting into the answer box and copying the question are blocked on the phones.
    • A player who leaves the quiz page (switches app or tab) during a question gets a warning, and their name appears on the Watch list on the big screen.

    Host

    • Type admin as the nickname, then the admin password, to open the host screen.
    • Questions opens the editor: multiple choice, true or false, or write a query. Export and import them as a file.
    • The host browser runs the game: keep this tab open. Players connect to it directly (WebRTC), so both sides need internet.
