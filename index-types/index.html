      Using the index-types demo

      Scenes

      • Clustered vs non-clustered: the same table with a clustered index on id and a secondary index on age; a range query on each.
      • Dense vs sparse: one entry per record vs one per page, and a lookup in both.
      • Bitmap: one bit vector per value; AND and OR queries.
      • GIN: inverted index from each tag to its posts; a "contains both" query.
      • GiST: points grouped into bounding boxes; an area search that skips boxes.
      • BRIN: min/max per block range; a range query that skips blocks.
