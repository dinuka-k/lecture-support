    How a node is stored

    Every node is one disk page (e.g. 8 KB), identified by its page number.

    P0K1P1K2P2…

    Internal page: separator keys between child-page pointers. P0 leads to keys < K1, P1 to K1 ≤ key < K2, and so on.

    K1RIDK2RID…next

    Leaf page: (key, row pointer) pairs in key order. A row pointer (RID) = (heap page, slot) of the row in the table file. The last field points to the next leaf page.

    Why so few levels? With 4-byte keys and 6-byte pointers an 8 KB page holds ~800 pointers, so 3 levels index 800³ ≈ 500 million rows: a lookup is ~3 index page reads + 1 table page read.

    Using the B+ tree demo

    Operations

    • Type one or more keys (42 or 10, 20, 5) and press Insert, Search or Delete. Enter inserts.
    • Disk view (top bar) draws each node as a page: page number, child-page pointers, (key, row pointer) entries and the next-leaf pointer, with the table's heap pages below. Searches end by following the row pointer.
    • Range: type two keys (20 60) — one search down, then a walk along the linked leaves.
    • Drag a number from the key tray onto the canvas to insert it, or onto Search to look for it. Click a tray number to insert it.
    • Drag a key out of the tree onto Delete to delete it, or onto Search to search for it.
    • Random tree builds a tree instantly, handy before demonstrating deletion.

    Canvas

    • Drag the background to pan; scroll or pinch to zoom.
    • Drag a node by its border (or Shift-drag anywhere on it) to move it with its subtree. Double-click a node to put it back.
    • Double-click empty space to re-fit the tree.

    The rules for order m

    • All keys live in the leaves; internal nodes hold separators that only guide the search (equal keys go right).
    • Leaves are linked left to right, so range queries walk along the leaf level.
    • At most m children and m − 1 keys per node; non-root leaves keep ⌈(m−1)/2⌉ keys, internal nodes ⌈m/2⌉ − 1.
    • Leaf split: the first key of the new right leaf is copied up. Internal split: the median moves up.
    • Delete from the leaf; fix underflow by borrowing (update the separator) or merging (drop the separator). A deleted key may stay as a separator.
